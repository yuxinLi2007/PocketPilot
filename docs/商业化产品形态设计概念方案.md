## 一、设计基调

**一句话：爸妈手机背面的一枚"鹅卵石长条"——按一下，说一句话，手机把事办了。**

视觉语言：**燕麦米白铝质鹅卵石 + 深苔绿透光大按键 + 一体无缝机身**。设计原则五条：

1. **实体优先**——所有高频操作不依赖翻手机、看屏幕；
2. **零学习**——不用教提示词，按键即说，说错有纠正机会；
3. **老人能摸到**——大按键、强纹理、明确反馈（光/震/听）；
4. **子女愿买单**——燕麦米白 + 苔绿是"家居好物"的气质，像一件体面的礼物，而不是医疗器材；
5. **轻薄好拿**——比手机本体还薄，单手整圈环握。

## 二、品牌标志（v2.3 新增）

**图标（Mark）：一枚实心圆 + 两道同心弧**——圆是那颗按键，弧是说话的声波。产品本身就是标志，标志就是产品。两笔构成，6px 小尺寸仍可辨认，适合激光雕刻。

- **字标**：POCKETPILOT 全大写、几何无衬线（Segoe UI/Inter 字族）、宽字距；副标语 **ONE PRESS · ONE SENTENCE**。
- **色彩**：苔绿 #4F5D3C（图标）、炭黑 #2C2C2A（浅底字标）、燕麦米白反白版（深底/雕刻）。

- **其他应用**：App 图标用纯图标版；包装盒用横排组合；说明书用单色版。

## 三、CMF 方案（v2.1 定稿方向，v2.2 调整）

| 部位 | 材质/颜色 | 规格 |
|-|-|-|
| 正面外观盖 | **燕麦米白阳极氧化铝**（#E9E2D2，喷砂哑光） | 0.6mm 铝，温润金属质感、抗刮、不留指纹 |
| 中框 + 背壳 | **同色系哑光 PC+ABS**（近 #E9E2D2） | 承载磁铁嵌槽、天线净空、USB-C 开孔 |
| 主键按压区 | **深苔绿**（#4F5D3C），**半透明键帽** | 直径 12mm，内嵌凹槽（见防误触设计），内部 LED 透光 |
| 预设键 ×2 | 深苔绿同色，凸点区分（1 点 / 2 点） | 直径 7mm，内嵌凹槽 |
| 灯缝 | **已取消（v2.2）** | 一体无缝成型，防水防尘更好、装配少一道缝 |

**为什么铝只做正面盖（重要工程约束）**：金属会屏蔽 2.4GHz 信号。蓝牙天线必须放在塑料中框/背壳一侧，铝盖下方不能有天线走线。这个约束同时带来两个好处：背壳用塑料便于磁铁嵌槽与减重，正面铝盖提供"子女愿意送礼"的质感。

**状态灯新方案（灯缝取消后）**：主键本身是指示灯——半透明苔绿键帽，内部 LED 透出。语义：慢闪暖白=未连接；快闪暖白=监听中；呼吸苔绿=执行中；**常亮苔绿=成功**；砖红闪=失败。灯就在手指按着的地方，反馈路径最短。

**苔绿 vs 原橙色的取舍（如实说明）**：深苔绿在燕麦米白面上的明度对比度约 4.5:1，辨识度充足；相比橙色更显高级、贴合"家居好物"定位。老年黄化视觉对蓝色最不敏感、绿橙尚可，加上凹槽定位 + 纹理 + 位置固定三重兜底，盲操不依赖颜色。

## 五、主机模块设计（v2.2/v2.3 当前形态）

### 5.1 尺寸与握感

- 外形：**扁长胶囊（细长鹅卵石），60 × 32 × 6.3 mm**，两端半圆（R16），重量约 **26g**（约 4 枚一元硬币）；
- 对比 v1.0：厚度 −34%（9.5→6.3mm）、重量 −26%（35→26g）、体积约减一半；
- **比手机本体（≈8mm）还薄**，吸在手机背面几乎无凸起感；比最薄的磁吸充电宝（8.6mm）薄 2mm；
- **扁长的两个收益**：①32mm 窄腰可以被手指整圈环握（38mm 圆饼做不到），掌心满握；②机身变长腾出电池空间，容量从 150mAh 回到 **180mAh**，续航从 4-5 天回升到 **5-6 天**；
- 2.5D 弧面收边，无棱角硌手。

### 5.2 按键布局与防误触设计（v2.3 核心）

**"控制岛"布局**：三个键全部集中在顶面靠上端的**凹槽控制岛**内，主键居中、两个预设键在其下方左右分布；其余机身表面**没有任何按键**——摸到凹槽就摸到了全部功能，其余区域随便握。

| 按键 | 位置 | 规格 | 默认功能 |
|-|-|-|-|
| 主键（苔绿透光） | 控制岛中心，距端部 ≥14mm | 凹槽 Ø16 深 1.0mm，键帽 Ø12 低于铝面 0.4mm，同心圆纹理 | **长按 ≥300ms = 按住说话，松开执行**；双击 = 重放上次任务；短按单击 = 无动作 |
| 预设键 ×2 | 控制岛内主键下方两侧 | 凹槽 Ø10 深 0.8mm，键帽 Ø7，凸点区分（1 点 / 2 点） | 子女在 App 里配置，如"女儿"=拨号、"回家"=导航；**长按 ≥500ms 触发** |

**防误触六条（物理 3 + 软件 2 + 结构 1）**：

1. **凹槽内嵌**——键帽低于铝面 0.4mm，布面、桌面、口袋内壁都压不到按键；
2. **围堰护圈**——凹槽外缘 0.4mm 环形凸台，只有指尖能伸入凹槽，平面物体进不去；
3. **控制岛避让区**——三键集中在顶面上半区、距外轮廓 ≥8mm，避开握持手掌重心带与口袋摩擦主带；
4. **长按门槛**——主键按下 <300ms 即松开视为误触，**静默忽略、无任何提示音**（不惊扰老人）；录音必须"按住不放"；
5. **短按无动作**——原来"短按重放上次任务"是误触重灾区（口袋里蹭一下就执行），改为**双击**才重放，两次有意操作；
6. **磁极防呆**——磁铁排布不对称，设备只能一个方向吸附，控制岛永远落在同一位置，老人不用想"哪头朝上"。

### 5.3 反馈系统（不依赖翻手机）

- **状态灯 = 主键本体透光**（半透明苔绿键帽 + 内置 LED）：慢闪暖白=未连接；快闪暖白=监听中；呼吸苔绿=执行中；常亮苔绿=成功；砖红闪=失败；
- **震动**：线性马达，短震=收到，双震=完成，长震=出错；
- **语音播报**：由手机端扬声器完成（"已打开微信"）——商业版 v1 不做设备端喇叭；
- **无屏幕**：屏幕交给手机，成本与厚度预算让给电池和结构强度。

### 5.4 麦克风

- **MEMS 麦克风（高约 1.0mm）**，开孔在顶面斜面、控制岛同端，朝上/朝外，远离手掌遮挡和手机扬声器；
- 薄机身拾音腔体变浅 → 侧向短声道 + 硅胶密封圈补偿（见 7.3）；
- 拾音距离目标 20-100cm（手持说话 / 平放桌面说话都可用）。

### 5.5 电池与充电

- 电池 3.0mm 薄型锂电 **180mAh**（扁长形态腾出的空间，比 v2.0 的 150mAh 多 20%）；
- 目标续航 **5-6 天**：按键唤醒 + 深度睡眠（非持续监听）+ BLE 低功耗连接策略；
- 充电两路：USB-C 口（模块底边）+ 底座 pogo 触点（对准即充，老人不用插线）；
- 低电时按键砖红呼吸 + 手机 App 推送给子女。

## 六、磁吸系统与手机兼容性

- **引磁环贴片**：不锈钢环 + 3M 无痕胶，长条形椭圆环（约 66×38mm 外圈）避开无线充电线圈区和 NFC 天线区；
- **磁极防呆**：磁铁排布不对称，只能一个方向吸附（配合按键防误触第 6 条）；
- **磁铁减薄的补偿**：磁铁 1.0mm（N52 高牌号）+ 贴片铁氧体导磁，指标：**垂直剥离力 ≥ 3N，甩不脱、单手可取下**；
- **定位模板卡**：硬卡纸开孔模板，卡在手机边缘比着贴，子女 30 秒贴正；
- 兼容性：裸机可吸、手机壳外可吸（贴在壳外）、支持 MagSafe 的手机可直接吸（吸力更强）。

## 七、桌面底座

- 与主机同语言的"大鹅卵石"，同 CMF（燕麦米白铝面 + 苔绿点缀），内部配重防滑；
- 顶面微凹托位 + pogo 充电触点，模块"随手一放"就对准；
- 底座本身**无电子智能**（不做网关、不做音箱），把成本留给主机——它只负责充电和"给设备一个家"。

## 八、电子方案与薄化工程账

### 8.1 芯片选型：ESP32-S3-PICO-1（SiP）

核实依据（乐鑫官方规格书）：ESP32-S3-PICO-1 是 7×7mm LGA56 封装的系统级封装（SiP），**高度仅 0.96mm**，内置晶振、滤波电容、Flash/PSRAM、射频匹配。对比 MINI-1 模组（2.4mm），**直接省 1.4mm 厚度**，且固件同样零改动迁移（同为 ESP32-S3 家族）。

| 方案 | 芯片 | 高度 | 单颗成本 | 建议 |
|-|-|-|-|-|
| **A（推荐）** | ESP32-S3-PICO-1 SiP | 0.96mm | 约 ¥25-35（较贵） | 首发主打：最薄 + 固件全继承 |
| A'（备选） | ESP32-S3-MINI-1 模组 | 2.4mm | ¥12-18 | 若供货紧张，机身改 8.0mm |
| B | 国产低成本 SoC | — | ¥3-6 | 仅"纯按键版"考虑，识别方案需重做 |
| C | 通用 BLE SoC（nRF52 类） | — | ¥5-8 | 远期 ¥99 轻量版备选 |

### 8.2 厚度账（6.3mm 怎么来的）

| 层 | 厚度 | 说明 |
|-|-|-|
| 前壳（铝盖） | 0.6mm | 阳极氧化铝 + 内部塑料支撑框 |
| 主板层 | 3.0mm | **电池（3.0mm）与主板（PCB 0.6 + SiP 1.0 = 1.6mm）并排布置，取最大值** |
| 磁铁层 | +0.3mm | 磁铁嵌入背壳凹槽，仅外露 0.3mm |
| 背壳 | 0.9mm | 塑料，含磁铁嵌槽 |
| 合计 | ≈5.5mm | 加装配公差/缓冲泡棉 → **工程目标 6.3mm** |

### 8.3 薄化的风险与对策（如实列出）

| 风险 | 对策 |
|-|-|
| 金属壳屏蔽信号 | **铝只做正面盖，天线放塑料背壳侧**，铝盖下方无天线走线；薄版 RSSI 对比原型基线（−36dBm）实测 |
| 天线净空不足 | IFA 天线放远端，远离电池/磁铁/隔磁片 |
| 拾音腔体变浅 | MEMS 麦 + 侧向短声道 + 硅胶密封圈；ESP-SR 自带降噪，实测识别率不下降 |
| 峰值电流发热（识别时约 300mA） | 语音只在按下 3-5 秒内运行，占空比 <5%；铝盖兼作散热面 |
| 凹槽按键结构强度 | 控制岛区域铝盖局部加厚 0.2mm + 塑料支撑框；1.2m 跌落测试列入手板验证 |
| 磁铁减薄吸力下降 | N52 高牌号 + 加宽环径 + 贴片铁氧体导磁，验收标准不变（≥3N） |

## 十二、待验证清单（概念 → 定稿之前必须完成的）

1. **磁吸人机模型测试**：3D 打印 6.3mm 手板（喷燕麦米白 + 苔绿凹槽按键）让老人真实握持——捏取成功率、凹槽按键盲操准确率、磁吸取放动作、桌面单手挑起测试；
2. **防误触实测（v2.3 新增）**：模拟口袋/包内/握持场景各 50 次，误触发率应为 0；验证长按 300ms/500ms 门槛在老人手抖条件下的可用性；
3. **180mAh 续航实测**：实测"每天 10 次语音 + BLE 常连"是否达 5 天；
4. **薄版 + 铝盖天线实测**：IFA 天线在 6.3mm 铝盖机身内的 RSSI 与连接稳定性对比原型基线；
5. **引磁环兼容清单**：实测主流机型无线充电/NFC 是否被遮挡（重点：iPhone、小米、华为旗舰）；
6. **薄版拾音实测**：MEMS 麦短声道方案在不同握姿下的识别率不下降；
7. **苔绿按键老年辨识度走查**：弱光/远距/黄化视觉条件下"找绿色"的可达性（不达标则加深苔绿明度或改回高饱和暖橙）；
