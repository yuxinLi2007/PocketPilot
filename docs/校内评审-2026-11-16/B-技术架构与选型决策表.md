## 二、兼容性交叉检查（方案之间会不会打架）

| 检查 | 结论 |
|-|-|
| PICO-1（#2）× 5.5mm 机身（#19） | ✅ 0.96mm 芯片 + 3.0mm 电池并排，5.5mm 可闭合 |
| USB-C（#13）× 5.5mm | ⚠️ USB-C 座 3.2mm+PCB 0.8=4.0mm 是最高点，决定下限；布局须避让磁铁区 |
| 铝盖 × IFA 天线（#14） | ✅ 铝只做正面盖，天线在塑料侧——这是不可违背的硬约束 |
| 命令词 ASR（#3）× "导航去某地" | ❌ **不兼容**：命令词无法捕捉任意地名。功能口径必须限定为"打开地图 / 预设回家导航"。任意目的地 = L2/L3（#5/#6）启动后才可能 |
| 深度睡眠（#16）× BLE 常连（#10） | ⚠️ 睡眠唤醒后重连延迟影响"按住即说"体验，需在电源管理设计时实测唤醒-重连耗时 |
|  ACTION_DIAL（#9）× 零学习目标 | ✅ 跳拨号盘后老人只需按绿色拨出键，可接受；直接 CALL 虽少一步但权限敏感，不值 |
| 侧载分发（#17）× 子女配置流程 | ✅ 买单人即安装人，流程设计已围绕子女 |

## 三、证据不足、暂不决策的事项

1. **L2 小模型上不上**——缺真机拒识率数据。决策门槛：变体词表扩充后拒识率 >10% 则启动。
2. **最终厚度 5.5 还是 4.2**——缺手板握持 + OTA 双实测。决策门槛已定义（掉值 <5dB + 握持通过）。
3. **定价 199-299 / 399 / 年费服务**——缺付费意愿实验。校内阶段统一说"待验证假设"。
4. **方言包范围**——缺方言采集数据与目标用户地域分布。
